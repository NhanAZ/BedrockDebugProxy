# Enchanted post-transfer timeout observation

This note records a reproducible post-transfer timeout observed on 2026-09-16. It is evidence for a narrow
resource-pack prefetch change, not a claim that the Enchanted backend or every proxy path has one universal cause.

## Evidence

Capture `captures/session-20260916T053620Z` was generated by the stamped development binary at commit
`6665340e55fb8f5d13aafe1d6d123eac7798891a` with `--follow-transfers`. The selected target was
`factions-spawn.factions.connect.enchanted.gg:19132`.

- Hop 1 observed and rewrote the server `Transfer` packet, then completed a route probe.
- Hop 2 opened and received seven URL-advertised resource packs.
- Hop 2 reached `session.negotiated` and `session.spawned`.
- The upstream connection then sent `You were kicked: Timed out` while the proxy was forwarding the packet to the client.
- The manifest reports zero dropped events, truncated events, capture write errors, or decode errors.

The hop-2 dial started at 05:37:17 UTC, the URL archive events were recorded around 05:37:29 UTC, negotiation completed
around 05:38:07 UTC, and spawn plus the timeout occurred around 05:38:17 UTC. The timing is consistent with a backend
timeout budget being consumed while the proxy waits for its upstream-first resource-pack exchange. It does not prove
that the server's timeout is caused by URL retrieval alone.

## Change and boundary

The URL cache now downloads up to three advertised archives concurrently while preserving the original offer order when
publishing successful results. This reduces the time spent in the existing upstream-first barrier without changing
packet bytes, resource-pack validation, downstream chunk delivery, or transfer routing. The worker count is bounded to
avoid unbounded concurrent memory and HTTP pressure from a large offer.

The change does not make the proxy a transparent client, does not capture RakNet acknowledgements or retransmissions,
and does not establish that all Enchanted backends accept a terminating proxy. A failed or slow upstream remains an
observable capture failure.

## Validation plan

Run a stamped binary from the change on Enchanted, select a different minigame or backend, and retain the complete
capture. Confirm that URL pack archives are retained, hop 2 reaches negotiation and spawn, and no upstream timeout is
reported during the resource-pack exchange. Repeat The Hive as the minimum runtime baseline. Automated concurrency
coverage is in `internal/proxy/resource_pack_url_test.go`.
