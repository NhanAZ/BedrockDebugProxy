# Skin artifact evidence

Reviewed on 2026-08-31 against gophertunnel v1.61.0 at commit `283a5a97dfe65da94bcc0b401807f6aefa9e72ee`. These are dependency APIs and research references, not copied implementation source. Gophertunnel's dependency license and notices remain in the existing inventory.

- [protocol/skin.go](https://raw.githubusercontent.com/sandertv/gophertunnel/283a5a97dfe65da94bcc0b401807f6aefa9e72ee/minecraft/protocol/skin.go) defines image dimensions, RGBA channel order, cape data, geometry, animations, and pixel-byte validation. Its introductory slice-length comments omit the four-channel multiplier in places. The actual validation uses width times height times four, which the view checks with overflow-safe bounds before PNG encoding.
- [packet/player_skin.go](https://raw.githubusercontent.com/sandertv/gophertunnel/283a5a97dfe65da94bcc0b401807f6aefa9e72ee/minecraft/protocol/packet/player_skin.go) associates a UUID with a skin. [packet/player_list.go](https://raw.githubusercontent.com/sandertv/gophertunnel/283a5a97dfe65da94bcc0b401807f6aefa9e72ee/minecraft/protocol/packet/player_list.go) delegates its entries to the codec. [protocol/player.go](https://raw.githubusercontent.com/sandertv/gophertunnel/283a5a97dfe65da94bcc0b401807f6aefa9e72ee/minecraft/protocol/player.go) puts the action on each entry and skips skin fields for removals. Do not assume the older packet-wide action layout.
- [login/data.go](https://raw.githubusercontent.com/sandertv/gophertunnel/283a5a97dfe65da94bcc0b401807f6aefa9e72ee/minecraft/protocol/login/data.go) describes base64 login skin, cape, geometry, patch, and animated image fields. The view reads only these fields from `session.connection_metadata`, not the whole `ClientData` struct, because unrelated large integers use the project's lossless structured-view wrappers.

The pinned decoder supplies serialization and malformed-input behavior. The new code changes no wire definition. Synthetic tests check add and removal entries, both skin directions through the loopback proxy, login snapshots, duplicate images, geometry byte retention, and PNG pixel equality including transparent pixels. Real-client appearance and performance remain separate validation requirements.
