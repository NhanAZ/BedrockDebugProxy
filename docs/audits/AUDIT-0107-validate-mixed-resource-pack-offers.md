# Audit AUDIT-0107

## Intent

Add a deterministic root integration regression test for mixed URL and RakNet resource-pack offers and update the research record with the validation boundary.

## Scope

- Add `TestRunnerPreservesMixedResourcePackOfferOrder` in `internal/proxy/proxy_test.go`.
- Exercise URL, non-URL, URL pack order through a local HTTP fixture, a local gophertunnel listener, and the BedrockDebugProxy runner.
- Verify that downstream `ResourcePacksInfo` entries retain UUID, version, size, and order while URLs are cleared, and that `ResourcePackStack` order and base-game version are retained.
- Update `docs/research/resource-pack-negotiation.md` and `docs/fix-history.md`.

## Evidence and provenance

The fixture uses synthetic resource-pack archives generated by the existing test helper. The local listener and HTTP server are loopback-only. The client declines pack downloads so the test covers negotiation metadata and stack ordering without claiming resource-pack application or public-server behavior.

## Automated validation

- `gofmt -w internal/proxy/proxy_test.go`
- `go test ./internal/proxy -run '^TestRunnerPreservesMixedResourcePackOfferOrder$' -count=5 -v`
- `git diff --check`
- Full `tools/quality.ps1 -LowMemory` and the final staged diff check are required before commit.

## Live validation status

No public-server or real-client validation was performed. The Hive mixed-offer flow remains pending and requires an owner-controlled capture with the exact tested binary if such an offer is observed.

## Known limitations and follow-up

The regression test does not prove that a vanilla client applies mixed URL and non-URL archives or that any public server emits this offer shape. Preserve the raw offer in a closed capture and run the real-client validation workflow before treating the behavior as live-compatible.
