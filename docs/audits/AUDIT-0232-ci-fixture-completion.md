# AUDIT-0232 - Wait for completed fixture startup in CI

This test-only change addresses two failures in [Quality run 39172130935](https://github.com/NhanAZ/BedrockDebugProxy/actions/runs/39172130935) for documentation commit 52e23b0045da46141b037dda2347089463188424. Runtime, networking, protocol, capture, resource-pack, CLI, and viewer behavior are unchanged. It does not change a validation report or server-specific behavior.

The Linux race job failed the ordinary reconnect case of TestRunnerFollowsTransferAndAcceptsNextHop. The test closed its second client immediately after the downstream spawn notification, while the proxy was still completing the upstream startup acknowledgement. Run returned a canceled startup. The fixture now emits a synthetic child SetTime marker after upstream startup. The test waits for that packet through the initialized bridge before closing. It keeps the ordinary and overlapping reconnect cases, equal nonzero GUID and local UDP assertions, successful probe-before-dial ordering, both startup events, and old physical connection evidence. No sleep or error allowance replaces those assertions.

The Windows job failed the first PHP lint subprocess after 10.18 seconds with empty output. That timing matches its ten-second context budget, but the prior diagnostic does not independently prove the termination cause. The optional companion check now uses a bounded thirty-second budget tied to the test context, consistent with the existing companion integration test, and records context state before cancellation when lint fails. PHP checks are not skipped or weakened. Syntax, the personality fixture, and PHAR packaging remain required when PHP is installed.

Focused transfer race checks passed three repetitions for both reconnect cases. The companion syntax and package check passed two repetitions separately. Canonical tools/format.ps1, tools/quality.ps1 -LowMemory, and whitespace checks passed before commit, with zero static-analysis issues and no called vulnerabilities. Exact-head Linux and Windows CI must pass before this change is considered complete.

This changes no producer contract or consumer runtime and needs no new authenticated server session. The matched BedrockPackArchive importer and actual stamped producer-verifier fixture checks remain recorded in AUDIT-0231. The maintainer stopped exploratory minigame visits and restricted collection to established child pack routes. No further server or minigame connection is made for this CI correction. The producer's official retail release gate remains separate and unfulfilled.
